Despliegue físico

  1. Clonar el repositorio en Ubuntu/WSL.
  2. Crear include/local_config.h sin publicarlo.
  3. Compilar con pio run -e panel_4848s040.
  4. Cargar por USB con pio run -e panel_4848s040 -t upload.
  5. Verificar por serial a 115200 baudios y probar el endpoint real.

Este sitio acredita publicación y compilación. No sustituye una prueba física del panel, pantalla, táctil o Wi-Fi.

Fuente derivada y fijada desde wpv10barza/esp32-3C@2ebac821 para trazabilidad de tesis.
