Firmware preparado para actualización OTA por HTTPS.

GitHub → Unity Catalog Volume → Databricks Apps → HTTPS → ESP32 → SHA-256 → OTA slot → reboot

El dispositivo no depende de WSL, una IP LAN o la misma Wi-Fi que una PC. Solo requiere acceso a Internet.
